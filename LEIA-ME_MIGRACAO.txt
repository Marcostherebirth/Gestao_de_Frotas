GESTÃO DE FROTA RL CONNECT — BASE MIGRADA

Esta pasta contém o aplicativo Streamlit, o banco SQLite já preenchido e a planilha original como cópia de segurança.

Como usar:
1. Instale Python 3.10+ no computador servidor.
2. Abra o Prompt/PowerShell nesta pasta.
3. Execute: python -m pip install streamlit pandas openpyxl
4. Execute: python -m streamlit run app.py
5. Acesse: http://localhost:8501

Para outros computadores na mesma rede, inicie com:
python -m streamlit run app.py --server.address 0.0.0.0
E acesse http://IP_DO_SERVIDOR:8501. Libere a porta 8501 no Firewall do Windows.
